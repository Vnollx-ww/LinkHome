# LinkHome 智能家居 APP 模块化需求文档总览

## 1. 文档目标

本文档目录用于承载 LinkHome 智能家居系统的模块化产品需求、技术架构与数据库设计。每个业务模块均包含三类文档：

- **PRD.md**：描述用户价值、业务流程、功能边界、交互形态、异常场景与验收标准。
- **技术架构.md**：描述前后端职责、接口设计、状态流转、实时通信、权限校验、核心实现原理。
- **SQL.md**：描述该模块涉及的数据表、字段含义、索引、约束与初始化数据建议。

## 3. 产品设计原则

- **好用优先**：普通家庭用户 3 步内完成常用设备控制，核心路径不依赖复杂配置。
- **实时可信**：设备状态必须尽可能展示真实状态，离线、控制中、失败、延迟均需明确反馈。
- **安全可控**：家庭数据、设备控制、安防告警必须经过权限校验和操作审计。
- **模块解耦**：设备、场景、告警、消息、统计之间通过事件和标准数据模型协作。
- **渐进增强**：先支持模拟设备与本地调试，再扩展真实硬件协议、云推送和第三方平台。

## 4. MVP 范围

- **必须实现**：账号登录、家庭管理、房间管理、设备模拟添加、设备列表、设备详情控制、WebSocket 状态同步、手动场景、基础自动化、告警消息、能耗统计。
- **建议实现**：成员邀请、权限分级、摄像头模拟画面、告警确认、消息已读、设备运行日志。
- **后续扩展**：真实 WiFi/Zigbee/BLE 配网、第三方语音平台、AI 场景推荐、地理围栏、视频云存储。
