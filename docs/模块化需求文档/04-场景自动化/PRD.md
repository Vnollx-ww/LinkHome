# 场景自动化模块 PRD

## 1. 模块定位

场景自动化模块让用户从单个设备控制升级为组合控制和条件联动。它是智能家居从“可远程控制”走向“真正智能”的核心模块。

## 2. 用户目标

- 一键执行多个设备动作。
- 根据时间、设备状态、环境条件自动执行动作。
- 能清楚知道自动化是否开启、何时触发、执行结果如何。
- 配置过程简单，可视化，避免复杂编程感。

## 4. 自动化模型

一条自动化规则由三部分组成：

- **触发器 Trigger**：什么时候开始判断，例如每天 18:00、门窗打开。
- **条件 Condition**：是否满足执行约束，例如周一到周五、家中有人、温度高于 30℃。
- **动作 Action**：执行什么，例如打开空调、关闭灯、推送消息。

## 5. 典型场景

### 5.1 回家模式

- 触发：用户点击“回家模式”。
- 动作：打开客厅灯、打开空调、关闭安防布防。
- UI：场景卡片使用房屋图标，执行中显示进度。

### 5.2 观影模式

- 触发：用户点击“观影模式”。
- 动作：关闭窗帘、调暗灯光、打开投影插座。
- UI：深色卡片，适合在首页常用场景展示。

### 5.3 高温自动开空调

- 触发：温度传感器温度 > 30℃。
- 条件：每天 10:00-22:00 生效。
- 动作：打开空调，设置 26℃ 制冷。

### 5.4 夜间门窗告警

- 触发：门窗传感器打开。
- 条件：晚上 23:00-次日 06:00。
- 动作：推送告警、打开走廊灯。

## 6. 页面与 UI 草图描述

### 6.1 场景首页

- **顶部 Tab**：手动场景、自动化。
- **手动场景卡片**：图标、名称、动作数量、执行按钮。
- **自动化卡片**：名称、触发摘要、动作摘要、启停开关。
- **空状态**：插画 + “创建你的第一个智能场景”。

### 6.2 创建场景页

- **基础信息区**：名称、图标、颜色。
- **动作编排区**：按顺序展示动作列表。
- **添加动作按钮**：选择设备，选择属性，设置目标值。
- **预览区**：用自然语言展示“将打开客厅灯，并把亮度调到 80%”。

### 6.3 创建自动化页

- **步骤 1**：选择触发器。
- **步骤 2**：设置附加条件。
- **步骤 3**：设置执行动作。
- **步骤 4**：确认规则摘要并保存。

## 7. 异常场景

- **动作设备已删除**：场景标记为异常，提示用户修复。
- **设备离线**：执行时跳过或失败，结果中明确展示。
- **循环触发**：禁止自动化直接或间接触发自身。
- **重复触发过快**：支持冷却时间，默认同一规则 60 秒内不重复触发。

## 8. 验收标准

- **一键场景可执行**：多个设备动作按配置执行。
- **自动化可触发**：时间和设备状态触发均可用。
- **结果可追溯**：每次执行有记录，失败动作有原因。
- **配置可理解**：保存前能用自然语言摘要展示规则。
