# 安防监控与告警模块 PRD

## 1. 模块定位

安防监控与告警模块负责摄像头预览、传感器异常检测、告警推送、告警确认和历史追溯，是智能家居产品安全感和可靠性的核心体现。

## 2. 用户目标

- 随时查看家中摄像头画面。
- 异常情况能够第一时间收到提醒。
- 能判断告警是否已处理。
- 可查看历史告警和设备触发原因。

## 4. 告警类型

| 类型 | 等级 | 来源设备 | 说明 |
| :--- | :--- | :--- | :--- |
| SMOKE_DETECTED | 紧急 | 烟雾传感器 | 检测到烟雾 |

## 5. 页面与 UI 草图描述

### 5.1 监控首页

- **顶部**：布防状态卡片，例如“当前家庭处于在家模式”。
- **摄像头区域**：两列网格展示摄像头缩略图。
- **告警区域**：最近告警列表，显示等级、设备、时间、处理状态。
- **快捷入口**：全部告警、布防设置、通知设置。

### 5.2 摄像头直播页

- **视频区域**：顶部大画面，黑色背景。
- **控制区**：截图、录像、麦克风、全屏。
- **云台区**：方向按钮放在底部。
- **信息区**：在线状态、码率、最近活动。

### 5.3 告警详情页

- **顶部等级**：红色/橙色/蓝色展示告警严重程度。
- **核心信息**：设备、房间、触发时间、触发属性。
- **处理动作**：确认、标记已处理、联系家庭成员。
- **关联数据**：设备历史状态、相关摄像头入口。

## 6. 告警生命周期

| 状态 | 说明 |
| :--- | :--- |
| NEW | 新告警，未读未确认 |
| NOTIFIED | 已推送 |
| ACKNOWLEDGED | 用户已确认 |
| RESOLVED | 已处理 |
| IGNORED | 用户忽略 |

## 7. 核心流程

### 7.1 传感器告警流程

1. 设备属性发生变化。
2. 后端判断是否命中告警规则。
3. 创建告警事件。
4. 写入消息中心。
5. WebSocket 推送给家庭成员。
6. APP 弹出提醒。
7. 用户进入告警详情并确认。

### 7.2 紧急告警强提醒流程

1. 烟雾或水浸告警触发。
2. APP 收到紧急告警事件。
3. 立即展示全屏弹窗、震动、声音提醒。
4. 用户必须点击“我知道了”或“标记已处理”。
5. 系统记录确认人和确认时间。

## 8. 异常场景

- **摄像头离线**：预览卡片显示离线占位图。
- **告警重复触发**：同一设备同一类型告警在冷却期内合并。
- **用户未在线**：进入 APP 后从消息中心看到未读告警。
- **告警设备被删除**：历史告警保留设备名称快照。

## 9. 验收标准

- **告警可触发**：传感器状态异常时产生告警。
- **提醒及时**：在线用户 1 秒内收到 WebSocket 告警。
- **处理闭环**：告警可确认、可标记处理、可查看历史。
- **UI 明确**：不同等级告警颜色和提醒强度不同。
