# 智能家居系统技术选型清单 (Cactus Link)

## 1. 后端技术栈 (Java 生态)
*   **核心框架：** Spring Boot 3.x (适配 JDK 21)
*   **开发语言：** Java 21 (强制要求，利用虚拟线程处理并发模拟)
*   **持久层框架：** MyBatis-Plus
*   **通用 Mapper：** MyBatis-Plus BaseMapper
*   **数据库：** MySQL 8.x
*   **连接池：** HikariCP (Spring Boot 默认)
*   **实时通信：** Spring WebSocket (STOMP 协议)
*   **任务调度：** Spring Task (用于定时模拟传感器数据跳变)

## 2. APP 端技术栈 (Expo 生态)
*   **基础框架：** Expo (React Native)
*   **开发语言：** TypeScript
*   **调试环境：** Expo Go
*   **路由导航：** Expo Router (基于文件系统的路由)
*   **状态管理：** Zustand (轻量级状态共享)
*   **网络请求：** Axios (对接后端 REST 接口)
*   **实时监听：** StompJS / SockJS-client (对接后端 WebSocket)
*   **图标库：** Lucide React Native
*   **动画库：** React Native Reanimated (用于 UI 交互动效)

## 3. 模拟逻辑实现方案
*   **设备模拟：** 数据库状态机 (MySQL 存储 JSON 格式的设备属性)
*   **交互模拟：** 指令下发后由后端通过虚拟线程异步触发 WebSocket 状态回传
*   **环境模拟：** 后端 @Scheduled 定时任务随机更新传感器数值
