# 能耗统计与消息中心模块 PRD

## 1. 模块定位

能耗统计与消息中心模块负责帮助用户了解家庭设备用电情况、运行记录、系统通知和告警消息。它增强产品的可解释性、可追溯性和长期使用价值。

## 2. 用户目标

- 查看家庭今日、本周、本月用电情况。
- 找到耗电最高的设备。
- 查看设备运行和控制历史。
- 统一接收系统通知、告警、场景执行结果。

| :--- | :--- | :--- | :--- |

| EMS-002 | 设备能耗排行 | P1 | 按用电量排序 |

## 4. 页面与 UI 草图描述

### 4.1 能耗页

- **顶部总览卡片**：今日用电、本月用电、预计电费。
- **趋势图区域**：支持日、周、月切换。
- **设备排行**：展示设备图标、名称、房间、用电量、占比。
- **节能建议**：根据高耗电设备给出提示。

### 4.2 消息中心页

- **顶部分类 Tab**：全部、告警、设备、场景、系统。
- **消息卡片**：图标、标题、摘要、时间、未读红点。
- **批量操作**：全部已读、清理已读。
- **空状态**：无消息时展示安静的家插画。

### 4.3 消息详情页

- **标题区**：消息标题、类型、时间。
- **正文区**：详细内容。
- **关联动作**：查看设备、查看告警、查看场景执行记录。

## 5. 能耗计算规则

- 智能插座和部分设备上报 `currentPower`。
- 系统按固定间隔采样功率。
- 能耗估算公式：`用电量 kWh = 功率 W × 时间 h / 1000`。
- 对无功率数据设备，可按设备类型配置默认功率估算。
- MVP 可通过模拟任务生成能耗采样数据。

## 6. 消息类型

| 类型 | 说明 |
| :--- | :--- |
| ALERT | 告警消息 |
| DEVICE | 设备上下线、控制失败等 |
| SCENE | 场景执行成功或失败 |
| SYSTEM | 家庭邀请、权限变更、系统通知 |
| ENERGY | 能耗异常或节能建议 |

## 7. 异常场景

- **无能耗设备**：展示空状态并推荐添加智能插座。
- **数据缺失**：趋势图断点显示，不伪造连续数据。
- **消息过多**：分页加载，默认保留最近 90 天。
- **已删除设备消息**：保留设备名称快照。

## 8. 验收标准

- **消息可达**：告警、设备控制失败、场景执行结果能进入消息中心。
- **已读可用**：单条已读、全部已读状态准确。
- **能耗可看**：存在采样数据时能展示趋势和排行。
- **跳转准确**：消息关联设备、告警、场景时可跳转详情。
